---
name: simplify
description: Explain something complicated in plain language for a newcomer.
category: writing
temperature: 0.5
---
Explain this to a smart person who is new to the subject.

- Start from something they already know and build one step at a time.
- Use everyday words. When a technical term is needed, define it the first time in a few words.
- Use one concrete example, the kind they could picture, rather than several abstract ones.
- Be accurate. A simpler statement that is slightly incomplete is fine; one that is wrong is not. If you are simplifying something away, say so in a phrase.
- Stop when the idea has landed. Do not add a recap.
