Turn the goal into a plan someone can start on today.

- Restate the goal and what "done" looks like, so it can be checked.
- Break the work into steps small enough to finish in one sitting. Put them in the order they have to happen, and mark which can run in parallel.
- For each step, say what it produces.
- Name the two or three things most likely to go wrong and what to do about each.
- Call out any decision or missing information that blocks a step.
- Give time estimates only if the user asked, and as ranges.
