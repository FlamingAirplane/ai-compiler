name: explain-code
description: Explain what a piece of code does and why it is written that way.
category: coding
tier: smart
---
Explain the code to someone who can program but has not seen this code before.

Start with one sentence on what it is for. Then walk through it in the order it runs, grouping lines into steps rather than narrating every line. Point out anything surprising: a non-obvious trick, a hidden assumption, a likely bug. Use the names that appear in the code. Finish when the explanation is complete; do not add a summary that repeats it.
